About item 11: in ernie_image_turbo.json, the old code overwrote the prompt node's input with plain text. That bypassed the prompt-enhancement path. The new code writes the CSV prompt into the upstream text node 88:94 instead, so that path stays intact.

Behaviour changes to know about:
- The CSV argument is now required. The old fallback to E:\work\hermes\hopeRoad\scenes.csv is gone.
- The default workflow is now Qwen-Image-2512_16_9.json. The workflow files were renamed during the work, so I pointed the default at the new name. 16_9 is the same size and date as the old YouTuibe file; if that's the wrong file, pass the right one with -w.
- Exit codes:
  - 0: everything succeeded
  - 1: some scenes failed
  - 2: setup error, such as an unreadable CSV or workflow, or ComfyUI unreachable

Other files:
- tests/fake_comfyui.py: a fake ComfyUI server (HTTP and WebSocket) for testing without a real ComfyUI.
- tests/test_generate_images.py: the test suite. Run it with python -m pytest tests -v.
- readme.md: rewritten for the new options and behaviour.
